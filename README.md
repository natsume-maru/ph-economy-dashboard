# Kita & Bayan — Philippine Economy & GDP Simplified

Kita & Bayan is an interactive, citizen-centric web dashboard built to make macroeconomic concepts—such as Gross Domestic Product (GDP), inflation, labor metrics, and regional growth—accessible and intuitive for every Filipino.

By combining source data from the Asian Development Bank (ADB) and the Philippine Statistics Authority (PSA) with interactive tools, everyday household analogies, and dynamic visual charts, this platform bridges the gap between complex economic data and daily financial reality.

🌟 Key Features1. 💡 Conceptual Framework & Household Analogy SwitcherDual-View Learning: Toggle between a familiar Family Household Budget view and a National Macro View to grasp fundamental economic components (Gross Income, Spending/Consumption, Savings/Investment, and Remittances).Expenditure Formula Breakdown: Clickable interactive visual components explaining the standard macroeconomic formula:$$\text{GDP} = C + I + G + (X - M)$$
